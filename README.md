# 📊 GCI – Data Science & Machine Learning

Repositório dedicado aos estudos e atividades desenvolvidos durante o **GCI (Global Challenge Initiative)**, com foco em programação Python, manipulação de dados, análise estatística e introdução ao Machine Learning.

## 🎯 Objetivo

Desenvolver conhecimentos práticos em análise e manipulação de dados, utilizando bibliotecas do ecossistema Python para explorar conjuntos de dados, construir visualizações, aplicar técnicas estatísticas e desenvolver modelos preditivos de aprendizado de máquina.

## 🛠️ Tecnologias e Bibliotecas

| Biblioteca | Aplicação |
|---|---|
| **Python** | Linguagem principal |
| **NumPy** | Computação numérica e operações com arrays |
| **Pandas** | Manipulação, limpeza e organização de dados |
| **Matplotlib** | Criação de gráficos e visualização de dados |
| **Seaborn** | Visualização estatística de dados |
| **Scikit-learn** | Algoritmos de Machine Learning e avaliação de modelos |
| **Requests** | Requisições HTTP e obtenção de dados |
| **SciPy** | Computação científica e métodos estatísticos |

## Conteúdos estudados

- Manipulação e análise de conjuntos de dados.
- Limpeza e pré-processamento de dados.
- Análise exploratória de dados (EDA).
- Estatística e correlação entre variáveis.
- Visualização de dados por meio de gráficos.
- Aprendizado supervisionado (*Supervised Learning*).
- Regressão Linear Simples e Múltipla.
- Treinamento e avaliação de modelos preditivos.
- Divisão de dados em conjuntos de treinamento e teste.

## Machine Learning

Introdução aos principais conceitos de aprendizado de máquina, incluindo:

- Regressão e classificação.
- Seleção de variáveis (*Features*).
- Treinamento de modelos (`fit`).
- Predições (`predict`).
- Avaliação de desempenho (`score`).
- Métricas de avaliação e generalização.

## Organização

O repositório reúne notebooks, exercícios práticos e implementações desenvolvidos ao longo do curso, acompanhando minha evolução nos estudos de Ciência de Dados e Machine Learning.
